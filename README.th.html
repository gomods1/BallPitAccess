BALL x PIT Access

ม็อดที่ทำให้เล่น BALL x PIT (Kenny Sun / Devolver Digital) ได้โดยไม่ต้องมองเห็น ม็อดจะอ่านทุกเมนูผ่าน โปรแกรมอ่านหน้าจอของคุณ ให้คุณเล่นทั้งเกมได้ด้วยคีย์บอร์ด และเปลี่ยนสนามรบให้เป็นเสียง: ศัตรู ลูกบอลของคุณ กระสุนของศัตรู อัญมณี XP และไอเท็มพิเศษ ต่างก็มีเสียงของตัวเอง ซึ่งดังมาจากฝั่งที่สิ่งนั้นอยู่เทียบกับตัวคุณ

เวอร์ชัน 0.6.0 สำหรับเกมเวอร์ชัน 1.308 รวมถึง DLC ริเซนบอลบิลอน (Risen Ballbylon) ม็อดพูดได้ทุกภาษา ที่เกมมี และจะใช้ภาษาตามการตั้งค่าภาษาของเกม

สิ่งที่ต้องมี

  • BALL x PIT บน Windows (Steam) เวอร์ชัน 1.308
  • โปรแกรมอ่านหน้าจอ: ทดสอบกับ NVDA แล้ว โปรแกรมอื่นที่ไลบรารีเสียงพูด Prism รองรับ (JAWS, Narrator, เสียง SAPI) ก็น่าจะใช้ได้เช่นกัน
  • MelonLoader 0.7.3 (x64) ตัวโหลดม็อด ใช้ฟรี ดาวน์โหลดได้จากหน้ารีลีสอย่างเป็นทางการบน GitHub
  • หูฟังหรือลำโพงสเตอริโอ: ซ้ายและขวามีความสำคัญมากในการต่อสู้

การติดตั้ง

ใช้ตัวติดตั้ง (ง่ายที่สุด): ดาวน์โหลด BallPitAccessibilityInstaller.exe จาก รุ่นล่าสุด แล้วเปิดใช้งาน ตัวติดตั้งจะหาเกมผ่าน Steam ติดตั้ง MelonLoader 0.7.3 ไลบรารีเสียงพูด Prism และม็อด และภายหลังสามารถอัปเดตหรือถอนออกได้ จากนั้นเปิดเกม การเปิดครั้งแรกจะใช้เวลาหลายนาทีและไม่มีเสียงขณะที่ MelonLoader เตรียมไฟล์ของเกม แล้วโปรแกรมอ่านหน้าจอจะเริ่มพูด

ติดตั้งเอง: ดาวน์โหลด BallPitAccess-vX.Y.Z.zip จากหน้าเดียวกัน แล้วแตกไฟล์ทั้งหมดลงในโฟลเดอร์เกม (ค่าเริ่มต้นคือ C:\Program Files (x86)\Steam\steamapps\common\BALLxPIT ซึ่งเป็นโฟลเดอร์ที่มี Balls.exe) ให้ version.dll อยู่ข้างๆ Balls.exe ไฟล์ zip มี MelonLoader อยู่แล้ว จึงไม่ต้องติดตั้งแยก เปิดเกม การเปิดครั้งแรกจะช้าและไม่มีเสียงเหมือนด้านบน

การถอนม็อด

ปุ่มถอนการติดตั้งของตัวติดตั้งจะลบม็อดและ MelonLoader และเก็บการตั้งค่าของคุณไว้ใน UserData หากต้องการถอนเอง:

ลบ Mods\BallPitAccess.dll และ prism.dll หากต้องการถอน MelonLoader ด้วย ให้ลบ version.dll และ โฟลเดอร์ MelonLoader, Mods, Plugins และ UserData ออกจากโฟลเดอร์เกม ม็อดไม่ได้เปลี่ยนแปลง ไฟล์ใดๆ ของเกม

ขั้นตอนแรก

  • กด F1 เมื่อใดก็ได้เพื่อดูวิธีใช้: มีครบทุกส่วน โดยเริ่มจากส่วนของที่ที่คุณอยู่ ลูกศรขึ้นและลงเพื่ออ่านทีละบรรทัด Tab เพื่อกระโดดไปส่วนถัดไป Escape เพื่อปิด
  • กด F4 เพื่อเปิดการตั้งค่าม็อด และในนั้นให้เปิด คู่มือเสียง: มันจะเล่นทุกเสียงในการต่อสู้ และบอกความหมาย การฟังสักครั้งก่อนเล่นรอบแรกจะช่วยได้มาก
  • ตัวเกมเองเมื่อใช้คีย์บอร์ดจะต้องใช้เมาส์ แต่เมื่อมีม็อด คุณไม่ต้องใช้เมาส์เลย ยกเว้นเครื่องยิงแบบไอเดิล (idle launcher) ในฐาน (ดู ข้อจำกัดที่ทราบ)

เสียงในการต่อสู้

กฎสามข้อนี้ใช้กับทุกเสียง โดยเทียบกับตัวละครของคุณเสมอ:

  • ฝั่ง: เสียงดังมาจากตำแหน่งของสิ่งที่มันบอก อยู่ทางซ้ายของคุณก็ดังทางซ้าย อยู่ทางขวาก็ดังทางขวา อยู่ตรงหน้าก็ดังตรงกลาง
  • ระดับเสียง: สูงขึ้นแปลว่าใกล้ขึ้น
  • อู้อี้ แปลว่ามันอยู่ข้างหลังคุณ

สิ่งที่เคลื่อนที่ตลอดเวลา (ลูกบอลของคุณ กระสุนศัตรู) เป็นเสียงต่อเนื่องที่ตามสิ่งนั้นไป ส่วนสิ่งที่ เปลี่ยนเป็นจังหวะ (ศัตรูที่เดินหน้า ไอเท็มที่วางอยู่บนพื้น) เป็นเสียงสั้นๆ

เสียง ความหมาย
กลองมือ ศัตรู ยิ่งเสียงสูงและเร็ว = ยิ่งใกล้ เมื่อศัตรูเคลื่อนที่ ตัวที่ใกล้ที่สุดจะดังทีละตัว ระหว่างที่ไม่มีอะไรเปลี่ยน จะดังเฉพาะตัวที่ใกล้ที่สุด
กลองใหญ่เสียงทุ้ม บอส มีกลอง ฆ้อง และแตรเมื่อบอสมาถึง
เสียงคำราม ศัตรูกำลังจะถึงตัวคุณ
เสียงหวีดที่สูงขึ้นเรื่อยๆ ศัตรูกำลังเตรียมโจมตี อยู่ทางฝั่งนั้น
เสียงหึ่งกลิ้งๆ (ต่อเนื่อง) ลูกบอลที่คุณรับได้ ดังจากตำแหน่งของลูกบอล และสูงขึ้นเมื่อลูกบอลเข้าใกล้คุณ คุณจึงได้ยินว่ามันกำลังมุ่งไปทางไหน สั่นเร็วขึ้นเมื่อลูกบอลใกล้ถึงแนวของคุณ และเบาลงขณะที่ลูกบอลยังอาจกระดอนจากศัตรูได้
เสียงคลิก คุณยืนอยู่ตรงจุดที่ลูกบอลจะตก: อยู่ตรงนั้น
เสียงตุบของถุงมือ รับลูกบอลได้
เสียงตุบทึบที่จมลง ลูกบอลหลุดผ่านคุณไป
เสียงขึ้นลำปืน ลูกบอลของคุณกลับมาแล้ว: คุณยิงได้ (ไม่มีเสียงเมื่อเปิดยิงอัตโนมัติ)
เสียงแก้วกริ๊ง คริสตัล EXP ทอง หรือทรัพยากรที่ควรเดินไปเก็บ: ชิ้นที่ใกล้ที่สุด หรือกองที่อยู่ไกลออกไปอีกนิด ของเหล่านี้ไม่เก็บเอง
เสียงคาลิมบาระยิบระยับ ไอเท็มพิเศษ: เครื่องปฏิกรณ์หลอมรวม พิมพ์เขียว ไข่ อุปกรณ์ลิฟต์ พลังชีวิต แม่เหล็ก ระเบิด ถุงอัญมณี
เสียงหวีดลม (ต่อเนื่อง) กระสุนศัตรูที่บินอยู่ใกล้คุณ เสียงสูงขึ้นเมื่อเข้ามาใกล้ ดังขึ้นเมื่อมันจะโดนคุณ
เสียงวูบตามด้วยเสียงแตก กระสุนจะโดนคุณ ดังมาจากตัวกระสุน: ก้าวหลบออกจากทางของมัน
เสียงหึ่งไฟฟ้า / เสียงช็อตสองครั้ง เลเซอร์กำลังเล็ง / คุณอยู่ในแนวของมัน ทั้งสองเสียงดังมาจากตัวเลเซอร์: ก้าวออกจากแนวนั้น
เสียงหวีดตกลงมา / เสียงฟู่ของชนวน ระเบิดกำลังตกลงมาใกล้ๆ / มันจะตกใส่คุณ ทั้งสองเสียงดังมาจากจุดที่มันจะตก: ก้าวหนีออกจากจุดนั้น
เสียงแฉะ คุณเหยียบอันตรายบนพื้น (ม็อดจะพูดชื่อของมัน)
เสียงต่อย / เสียงอึก ดาเมจ / การฟื้นฟู
เสียงหัวใจเต้น พลังชีวิตต่ำ เต้นเร็วขึ้นเมื่อต่ำมาก
เสียงโคลงเคลงมึนๆ คุณติดเอฟเฟ็กต์สถานะ
เสียงระฆังสองโน้ตไล่ขึ้น เพิ่มเลเวลได้แล้ว (กด E)
เสียงเคาะไม้ ขอบด้านข้างของสนาม (และสุดรายการในเมนู)
เสียงเคาะโลหะ ขอบด้านหน้าหรือด้านหลังของพื้นที่ที่คุณเดินได้
เสียงคลิกสวิตช์ ตัวช่วยเล็งเปลี่ยนไปยังเป้าหมายอื่น ดังจากฝั่งของเป้าหมายใหม่ เมื่อเปิดยิงอัตโนมัติ จะไม่ดังหลังกำจัดศัตรู

ทุกเสียงเหล่านี้ฟังได้ใน F4 → คู่มือเสียง โดยใช้ลูกศรซ้าย / ขวาเพื่อฟังจากแต่ละฝั่ง ระหว่างการต่อสู้ Q จะบอกชื่อเสียงที่คุณเพิ่งได้ยิน

ตัวกรองเสียง (ปุ่มตัวเลข)

ในการต่อสู้ ปุ่มตัวเลขจะปิดหรือเปิดเสียงแต่ละกลุ่ม เพื่อให้คุณมีสมาธิ เกมไม่ได้ใช้ปุ่มเหล่านี้เลย

ปุ่ม กลุ่ม
1 ศัตรู: กลอง เสียงคำราม การเตรียมโจมตี การมาถึงของบอส
2 ลูกบอล: เสียงหึ่งกลิ้งๆ เสียงคลิก การรับลูก การรับพลาด เสียงขึ้นลำปืน
3 รางวัล: อัญมณี ทอง ทรัพยากร ไอเท็มพิเศษ
4 กระสุนและอันตราย
5 ขอบสนาม
6 พลังชีวิตของคุณ: ดาเมจ การฟื้นฟู เสียงหัวใจเต้น สถานะ
7 เสียงคลิกตัวช่วยเล็ง
0 เปิดทุกอย่างกลับมา
  • แต่ละตัวเลขสลับกลุ่มของตัวเอง โดยไม่ขึ้นกับกลุ่มอื่น
  • Ctrl+ตัวเลข จะเหลือไว้แค่กลุ่มนั้น ตัวอย่าง: เฉพาะศัตรูและรางวัล = Ctrl+1 แล้วกด 3
  • สิ่งที่คุณเลือกจะถูกเก็บไว้สำหรับครั้งถัดไป เมื่อการต่อสู้เริ่มขณะที่มีบางอย่างปิดเสียงอยู่ ม็อดจะบอกว่า อะไรปิดเสียงอยู่
  • การปิดเสียงเปลี่ยนแค่เสียงเท่านั้น: ปุ่ม H, J, P, N ยังตอบอยู่ และตัวช่วยรับลูกยังหลบให้อยู่

ตัวช่วย

ทุกอย่างที่ตัวช่วยทำ คุณก็ทำเองได้ด้วยการฟัง ตัวช่วยมีไว้ให้เมื่อคุณต้องการ

  • ตัวช่วยเล็ง (F5 เพื่อเปลี่ยนโหมด): เล็งให้คุณไปที่ศัตรูที่ใกล้ที่สุด (ค่าเริ่มต้น) ศัตรูที่แข็งแกร่ง ที่สุด ศัตรูที่อยู่ตรงหน้าคุณ มุมคงที่ หรือปิด (ใช้เมาส์) ลูกศรใช้ปรับอย่างละเอียด มันเล็งส่วนของศัตรูที่ไม่มีศัตรูตัวอื่นบัง ข้ามศัตรูที่อยู่ในมุมที่ฮีโร่ยิงไม่ได้ และในโหมดเริ่มต้นจะเล็งบอสก่อน เว้นแต่ศัตรูตัวอื่นกำลังจะถึงตัวคุณ
  • ตัวช่วยรับลูก (กด Shift ค้างไว้): ตัวละครจะเดินไปอยู่ใต้ลูกบอลลูกถัดไปที่กำลังตกลงมา ถ้าไม่มีลูกบอลกำลังมา จะเดินไปยังอัญมณีหรือไอเท็มที่ใกล้ที่สุด ถ้ามีกระสุนกำลังจะโดนคุณ จะหลบออกไปก่อน W / S ยังใช้เดินไปข้างหน้าและถอยหลังได้ ส่วน A / D จะควบคุมแทนเสมอ ใน F4 ตั้งเป็นปิด “กด Shift ค้างไว้” (ค่าเริ่มต้น) หรืออัตโนมัติได้ เมื่อคุณบาดเจ็บ มันจะไปเก็บไอเท็มฟื้นพลังก่อน

การตั้งค่าม็อด (F4)

ลูกศรขึ้น / ลงเพื่อเลื่อน ลูกศรซ้าย / ขวาหรือ Enter เพื่อเปลี่ยน Escape เพื่อปิด การตั้งค่าจะถูกบันทึกไว้

  • โหมดตัวช่วยเล็ง
  • ตัวช่วยรับลูก: ปิด, กด Shift ค้างไว้, อัตโนมัติ
  • เสียงสัญญาณ เปิด / ปิด, ระดับเสียงสัญญาณ
  • เรดาร์ศัตรู เสียงลูกบอล ขอบสนาม กระสุนและอันตราย (เปิด / ปิด)
  • เสียงไอเท็ม: ปิด, เฉพาะไอเท็มพิเศษ, ทั้งหมด
  • เสียงพลังชีวิต เสียงคลิกตัวช่วยเล็ง (เปิด / ปิด)
  • อ่านคำอธิบายการอัปเกรดเมื่อโฟกัส
  • ปุ่ม (Enter เพื่อเปิด): ดู การเปลี่ยนปุ่ม
  • คู่มือเสียง (Enter เพื่อเปิด)
  • บันทึกดีบัก
  • บันทึกการต่อสู้ (ปิดเป็นค่าเริ่มต้น): ทุกการต่อสู้จะถูกเขียนลง UserData\BallPitAccess\telemetry.tsv เพื่อใช้ปรับเสียง

การเปลี่ยนปุ่ม

F4 → ปุ่ม แสดงปุ่มของม็อดทุกปุ่มพร้อมปุ่มที่ใช้อยู่ตอนนี้ ลูกศรขึ้น / ลงเพื่อเลือก กด Enter แล้วกดปุ่มใหม่ (Escape เพื่อยกเลิก) Delete เพื่อคืนปุ่มเริ่มต้น และบรรทัดสุดท้ายคืนค่าทุกปุ่ม ถ้าปุ่มใหม่เป็นของการทำงานอื่นของม็อด อยู่แล้ว ทั้งสองจะสลับกัน และม็อดจะบอกว่าการทำงานอีกอันย้ายไปที่ไหน ปุ่มที่เมนูหรือตัวเกมต้องใช้ (ลูกศร Enter Tab Escape Backspace Space W A S D F E R X) ใช้ไม่ได้ วิธีใช้ใน F1 จะจบด้วยปุ่มตามที่ตั้งไว้ตอนนี้

เคล็ดลับสำหรับรอบแรก

  • รับลูกบอลของคุณให้ได้ ลูกบอลที่รับได้จะยิงใหม่ได้ทันที ส่วนลูกที่พลาดจะใช้เวลา 2 ถึง 3 วินาทีกว่าจะ กลับมา ตามเสียงหึ่งกลิ้งๆ ไปจนกว่าจะได้ยินเสียงคลิก แล้วอยู่ตรงนั้น
  • เก็บอัญมณี XP ของคุณ ของพวกนี้ไม่ถูกเก็บเอง ตามเสียงแก้วกริ๊งไป ถ้าเสียงอู้อี้แปลว่ามัน อยู่ข้างหลังคุณ
  • เอาชีวิตรอดก่อน ช่วงต้นของรอบ การมีชีวิตรอดสำคัญกว่าดาเมจ
  • หลอมรวมและวิวัฒนาการลูกบอลของคุณเมื่อการเพิ่มเลเวลมีให้เลือก: ตัวเลือกจะบอกว่า “การหลอมรวม” หรือ “วิวัฒนาการ”
  • ลดความเร็วเมื่อเจอบอส ด้วย Num - (หรือปุ่มลบของตัวเกม) ม็อดจะเตือนคุณเมื่อบอสมาถึงขณะที่ความเร็วเกมสูง
  • การตายเป็นเรื่องปกติ: ทองที่คุณนำกลับมาใช้สร้างบอลบิโลนใหม่ และสิ่งปลูกสร้างจะทำให้ทุกรอบต่อจากนั้น แข็งแกร่งขึ้น

ข้อจำกัดที่ทราบ

  • เครื่องยิงแบบไอเดิล (idle launcher) ในฐานยังต้องใช้เมาส์
  • กระดานผู้นำและการโหวต Twitch อ่านได้แค่ขั้นพื้นฐาน ข้ามเครดิตไม่ได้
  • การตั้งค่าม็อดอยู่ที่ F4 ไม่ได้อยู่ในหน้าจอตัวเลือกของเกมเอง
  • ข้อความของม็อดเองในภาษาอื่นนอกจากภาษาอังกฤษและภาษาสเปน (รวมถึงภาษาไทย) ได้รับการแปลโดยยังไม่ได้รับการตรวจทาน จากเจ้าของภาษา ยินดีรับการแก้ไข ชื่อจากเกม (สิ่งปลูกสร้าง ลูกบอล ศัตรู การอัปเกรด) มาจากคำแปลของตัวเกมเองเสมอ
  • ระดับเสียง ความถี่ของเสียง และความกว้างของการรับลูก ยังไม่ได้ปรับแต่งร่วมกับผู้เล่น
