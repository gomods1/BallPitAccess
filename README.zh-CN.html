BALL x PIT Access

这是一个让视障玩家无需视力也能游玩 BALL x PIT（Kenny Sun / Devolver Digital）的模组。它通过你的读屏软件朗读每一个 菜单，让你只用键盘就能玩完整个游戏，并把战场变成声音：敌人、你的弹珠、敌人的子弹、经验宝石和特殊物品都有各自的声音， 从它们相对你所在的那一侧传来。

版本 0.8.0，适用于游戏版本 1.308，包括“升天球比伦”（Risen Ballbylon）DLC。模组支持游戏提供的所有语言， 并跟随游戏的语言设置。

你需要什么

  • Windows 版（Steam）BALL x PIT，版本 1.308。
  • 一款读屏软件：已测试的是 NVDA。Prism 语音库支持的其他读屏软件（JAWS、讲述人、SAPI 语音）应该也能使用。
  • MelonLoader 0.7.3（x64），模组加载器。免费，可从它的 GitHub 官方发布页面下载。
  • 耳机或立体声音箱：在战斗中，左右声道非常重要。

安装

使用安装程序（最简单）：从最新版本下载 BallPitAccessibilityInstaller.exe 并运行。 它会通过 Steam 找到游戏，安装 MelonLoader 0.7.3、Prism 语音库和模组，以后还能更新或卸载它们。然后启动游戏： 第一次启动需要几分钟，MelonLoader 准备游戏文件时没有声音；之后你的屏幕阅读器就会开始说话。

手动安装：从同一页面下载 BallPitAccess-vX.Y.Z.zip，把全部内容解压到游戏文件夹（默认为 C:\Program Files (x86)\Steam\steamapps\common\BALLxPIT，即包含 Balls.exe 的文件夹），让 version.dll 位于 Balls.exe 旁边。压缩包里已经包含 MelonLoader，不需要另外安装。启动游戏；第一次启动和上面一样，较慢且没有声音。

卸载模组

安装程序的“卸载”按钮会删除模组和 MelonLoader，并保留你在 UserData 中的设置。手动卸载：

删除 Mods\BallPitAccess.dll 和 prism.dll。如果也要卸载 MelonLoader，请从游戏文件夹中删除 version.dll，以及 MelonLoader、Mods、Plugins 和 UserData 这几个文件夹。模组不会修改任何游戏文件。

入门

  • 随时按 F1 打开帮助：包含全部内容，从你当前所在位置对应的部分开始。 上下方向键逐行阅读，Tab 跳到下一部分，Esc 关闭。
  • 按 F4 打开模组设置，在里面打开声音指南：它会播放每一个战斗声音并说明含义。在第一轮游戏前听一遍会很有帮助。
  • 游戏本身在使用键盘时依赖鼠标操作；有了这个模组，除了基地里的挂机发射器之外，你完全不需要鼠标 （见已知限制）。

H 资源和天数
J 采集和工人
K 逐格探索基地
I 放置或移动建筑时：这个位置会挡住谁
  • 建造：方向键把建筑移动一格，并告诉你能否放下；回车建造，R 旋转，Home 跳到空位，退格取消。
  • 采集：开始时会瞄准一个建筑。回车派出工人，Tab 瞄准另一个建筑，左右方向键转动瞄准，按住空格加速，Esc 退出。
  • 施工：正在建造或升级的建筑也在采集的 Tab 列表里。每个撞到它的工人都会推进建造，建成时模组会告诉你。在基地里对它按回车会开始瞄准它的采集。
  • 工人能到达吗？ 采集瞄准某个建筑时（Tab，或在基地对它按 Enter），Mod 会按游戏移动工人的方式追踪路线，并选一个能到达的角度：“工人能直接撞到”“工人从墙上反弹后能到达”“工人会经过它上面”（麦田），或“没有通路，森林挡在前面”。没有通路的建筑只能碰运气到达：把它或挡路的建筑挪开。左右方向键会说这条线撞到什么。
  • 采集结束后，Mod 会说每个在建建筑得到了多少（“鬼屋：撞到 6 次，从百分之40到百分之55”）。游戏自己的总结只统计资源：只要没采到东西就会显示“徒劳无功”，即使工人建造了。
  • 扩张：Tab 选择一块建造区域，回车购买。
  • 重新调整：Tab 选择一个建筑，回车拿起，方向键移动，回车放下。
  • 探索（K）：方向键每次走一格，并说出那里有什么：空格（以及向右、向下还有几个空格）、建筑和它的大小，或未购买的土地。Tab / Shift+Tab 跳到下一个 / 上一个空格。K、退格键或 Esc 退出。列和行与放置建筑时相同。
  • 建造菜单会说出每个建筑占多大地方（“宽3，高2”），开始放置时会说出名称和大小。
  • 放置或移动建筑：位置会说明被什么挡住（“被森林挡住”）。I 读出工人能否到达这个位置，以及它会挡住哪些建筑、让哪些建筑只能靠墙壁反弹到达。Home 寻找工人能直接打中、不挡住任何建筑的最佳空位，并旋转建筑以放得下。按 R 后会读出新的形状：有些建筑（比如鬼屋）不是长方形（“左上角空着”）。重新布置时也可以旋转建筑。
  • 探索：Page Down / Page Up 跳到下一个 / 上一个建筑，并读出位置、大小和形状。

战斗中会朗读的内容：开始时的关卡、Boss 以及它们生命值降到百分之 75、50 和 25 时的提示、受到的伤害和生命值、 状态效果、掉落的特殊物品、“有升级可用，按 E”，以及本轮结束。

战斗声音

以下三条规则适用于所有声音，始终以你的英雄为基准：

  • 方向：声音来自它所指的东西所在的位置：在你左边就在左边响，在你右边就在右边响，在正前方就在正中间。
  • 音调：越高表示越近。
  • 发闷表示在你身后。

一直在移动的东西（你的弹珠、敌人的子弹）是跟随它们的连续声音；按步骤变化的东西（前进的敌人、掉在地上的物品） 是短促的声音。

声音 含义
手鼓 敌人。音越高越快 = 越近。敌人移动时，最近的几个轮流响起；没有变化时只响最近的一个。
低沉的大鼓 一个 Boss。Boss 到来时会响起鼓、锣和号角。
咆哮 有敌人马上就要到你面前。
上升的呜呜声 一个敌人正在蓄力攻击，声音在它那一侧。
滚动的嗡嗡声（连续） 你能接住的弹珠。它从弹珠所在的位置响起，弹珠离你越近，音调越高，让你听出它往哪里飞；弹珠越接近你这一行，跳动越快；弹珠还可能被敌人弹开时，声音较轻。
咔嗒声 你站在弹珠的落点上：待在那里。
手套闷响 接住了弹珠。
沉闷下坠的闷响 一颗弹珠从你身边漏过去了。
上膛声 你的弹珠都回来了：可以射击（开启自动开火时不发声）。
玻璃叮声 应走去拾取的经验水晶、金币或资源：最近的一个，或稍远处的一堆。它们不会自动收集。
卡林巴琴闪亮音 一个特殊物品：融合核心、蓝图、蛋、齿轮、生命值、磁铁、炸弹、宝石袋。
轻柔的呼啸声（连续） 一发在你附近飞行的敌人子弹，越近音调越高。会打中你时声音更响。
嗖的一声加爆裂声 一发子弹会打中你；声音来自子弹：避开它的路线。
电流嗡嗡声 / 两声电击滋滋声 激光正在瞄准 / 你在它的射线上；两者都来自激光：离开这条射线。
下落的哨声 / 引信嘶嘶声 附近有炸弹正在落下 / 它会落在你身上；两者都来自它的落点：远离它。
噗叽声 你踩到了地面危险（会朗读它的名称）。
一拳 / 咕嘟声 受到伤害 / 得到治疗。
心跳 生命值低；非常低时更快。
晕乎乎的摇晃声 你中了一个状态效果。
两个上升的铃声 有升级可用（按 E）。
木头敲击声 场地的侧边（也表示菜单列表的末尾）。
金属敲击声 你活动区域的前方或后方边界。
开关咔嗒声 瞄准辅助切换到了另一个目标，在新目标那一侧响起。开启自动射击时，击杀后不响。

以上每一个声音都可以在 F4 → 声音指南中试听，用左右方向键分别在两侧收听。 战斗中，Q 会说出你刚才听到的声音。

声音过滤（数字键）

在战斗中，数字键可以静音或恢复一组声音，让你集中注意力。游戏本身不使用这些按键。

按键 声音组
1 敌人：鼓声、咆哮、蓄力、Boss 到来
2 弹珠：滚动的嗡嗡声、咔嗒声、接住、漏接、上膛声
3 奖励：经验宝石、金币、资源、特殊物品
4 子弹和危险
5 场地边缘
6 你的生命值：受伤、治疗、心跳、状态
7 瞄准辅助提示音
0 全部恢复
  • 每个数字键只切换自己那一组，与其他组互不影响。
  • Ctrl+数字键只保留那一组。例如：只听敌人和奖励 = 先按 Ctrl+1，再按 3。
  • 你的选择会保留到下次游戏。战斗开始时如果有声音被静音，模组会告诉你哪些被静音了。
  • 静音只影响声音：H、J、P、N 键仍然会回答，接球辅助也仍然会躲避。

辅助功能

辅助功能做的每一件事，你也都可以靠耳朵自己完成；辅助功能只是在你需要时提供帮助。

  • 瞄准辅助（F5 切换模式）：替你瞄准最近的敌人（默认）、最强的敌人、你正前方的敌人、一个固定角度，或者关闭（用鼠标）。 方向键可以微调。它瞄准敌人没有被其他敌人挡住的部位，跳过英雄无法射击的角度上的敌人；在默认模式下，除非有别的敌人马上就要碰到你，否则优先打Boss。
  • 接球辅助（按住 Shift）：英雄会走到下一颗落下的弹珠下方；没有弹珠飞来时，会走到最近的经验宝石或物品； 如果有子弹马上要打中你，会先躲开。W / S 仍然可以让你向前和向后移动，A / D 始终会接管控制。在 F4 中可以设为关闭、 “按住 Shift”（默认）或自动。你受伤时，它会先去捡回复道具。

模组设置（F4）

上下方向键移动，左右方向键或回车修改，Esc 关闭。设置会自动保存。

  • 生命值音效、瞄准辅助提示音（开启 / 关闭）
  • 聚焦时朗读升级描述
  • 手柄

更改按键

F4 → 按键列出每个模组按键以及它现在对应的键。上下方向键选择，按回车后再按新的键（Esc 取消）， Delete 恢复默认按键，最后一行把所有按键都恢复。如果新的键已经属于另一个模组功能，两者会互换，模组会告诉你 另一个功能换到了哪里。菜单或游戏需要的键（方向键、回车、Tab、Esc、退格、空格、W A S D F E R X）不能使用。 F1 帮助的最后会列出当前设置的按键。

手柄

  • 按键名称按 Xbox 手柄。PlayStation 或 Switch 手柄需要为本游戏打开 Steam Input
  • 战斗之外，十字键或左摇杆像方向键一样移动，A 是回车，B 返回
  • X 和 Y 跳到第一项和最后一项；放置建筑时，X 寻找放得下的位置，Y 旋转建筑
  • RB 和 LB 是 Tab 和 Shift Tab，RT 和 LT 切换界面的标签页
  • Start 是游戏的暂停
  • 战斗中摇杆、扳机和按键归游戏使用
  • 十字键上读敌人，下读生命，左读状态，右读进度
  • 按住左摇杆来接球，和 Shift 一样
  • 不动右摇杆时瞄准辅助替你瞄准；移动它就自己瞄准
  • 按住 View 还有更多：A 帮助，B 模组设置，X 读整个界面，Y 重复，Start 切换瞄准模式
  • View 加 LB 和 RB 读回顾列表中更早和更新的行，View 加摇杆按下在详情和事件之间切换
  • 战斗中 View 加十字键：上 危险，下 装备，左 物品，右 最后的声音；View 加 LT 和 RT 降低和提高游戏速度
  • 基地中 View 加十字键：上 收获，下 资源，左 探索模式
  • 菜单中 View 加 LT 和 RT 是 Page Up 和 Page Down

战斗中按下右摇杆打开战斗地图;在暂停菜单中按视图键和十字键右。在地图中十字键走动,RB 和 LB 在敌人之间跳转,A 锁定瞄准,B 关闭。

第一轮游戏的建议

  • 接住你的弹珠。 接住的弹珠可以立刻再次射出；漏接的弹珠要 2 到 3 秒才会回来。跟着滚动的嗡嗡声走，直到听见咔嗒声， 然后站住不动。
  • 拾取你的经验宝石。 它们不会自动收集。跟着玻璃叮声走；声音发闷表示在你身后。
  • 先活下来。 在一轮游戏的前期，活着比输出伤害更重要。
  • 升级提供选项时，记得融合和进化你的弹珠：选项会说“融合”或“进化”。
  • 遇到 Boss 时减速，用 Num -（或游戏自己的减号键）。如果 Boss 到来时游戏速度较快，模组会提醒你。
  • 死亡很正常：你带回来的金币用来建设新球比伦，而建筑会让之后的每一轮都更强。

已知限制

  • 基地里的挂机发射器仍然需要鼠标。
  • 排行榜和 Twitch 投票只能做基本的朗读。制作人员名单无法跳过。
  • 模组设置在 F4 中，不在游戏自己的选项界面里。
  • 除英语和西班牙语外，模组自身在其他语言中的文本是翻译的，尚未经过母语者审校。欢迎指正。游戏中的名称（建筑、弹珠、 敌人、升级）始终来自游戏自己的翻译。
  • 声音的音量、频率以及接球范围还没有和玩家一起调校过。

报告问题

游戏文件夹中有用的文件：

  • UserData\BallPitAccess\speech.log：模组朗读过的所有内容。
  • MelonLoader\Latest.log：模组的日志（错误、界面、接住和漏接）。
  • 在战斗中，Ctrl+Shift+D 会把 UserData\BallPitAccess\threats.txt（敌人、弹珠、子弹、拾取物及其位置）写入文件， 并把当前界面的列表写入 Latest.log：当某个声音指错方向，或者菜单朗读顺序不对时，这很有用。
  • UserData\BallPitAccess\telemetry.tsv：如果你开启了 F4 → 记录战斗。包含战斗中的每个声音、敌人、弹珠和 子弹。声音难以分辨时最有帮助。
