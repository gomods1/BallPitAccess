# BALL x PIT Access

**BALL x PIT**(Kenny Sun / Devolver Digital)을 화면을 보지 않고 플레이할 수 있게 해 주는 모드입니다. 모든
메뉴를 화면 낭독기로 읽어 주고, 게임 전체를 키보드로 조작할 수 있게 하며, 전장을 소리로 바꿉니다:
적, 내 볼, 적의 투사체, 경험치 보석, 특수 아이템이 모두 각자의 소리를 가지며, 나를 기준으로 그것이
있는 쪽에서 들립니다.

버전 0.8.0, 게임 버전 1.308용이며 부상한 볼빌론 DLC를 포함합니다. 이 모드는 **게임이 지원하는 모든
언어**로 말하며, 게임의 언어 설정을 따릅니다.

## 필요한 것 {#what-you-need}

- Windows(Steam)용 BALL x PIT, 버전 1.308.
- 화면 낭독기: 테스트한 것은 NVDA입니다. Prism 음성 라이브러리가 지원하는 다른 화면 낭독기(JAWS,
  내레이터, SAPI 음성)도 동작할 것입니다.
- 모드 로더인 **MelonLoader 0.7.3**(x64). 무료이며, 공식 GitHub 릴리스 페이지에서 받을 수 있습니다.
- 헤드폰이나 스테레오 스피커: 전투에서는 왼쪽과 오른쪽 구분이 매우 중요합니다.

## 설치 {#installing}

**설치 프로그램 사용(가장 쉬움):** [최신 릴리스](https://github.com/gomods1/BallPitAccess/releases/latest)에서
`BallPitAccessibilityInstaller.exe`를 내려받아 실행합니다. Steam을 통해 게임을 찾고 MelonLoader 0.7.3,
Prism 음성 라이브러리, 모드를 설치하며, 나중에 업데이트하거나 제거할 수도 있습니다. 그런 다음 게임을
실행합니다. 처음 실행할 때는 MelonLoader가 게임 파일을 준비하느라 몇 분이 걸리고 그동안 아무 소리도 나지
않습니다. 그 뒤 스크린 리더가 말하기 시작합니다.

**직접 설치:** 같은 페이지에서 `BallPitAccess-vX.Y.Z.zip`을 내려받아 모든 내용을 게임 폴더(기본 위치는
`C:\Program Files (x86)\Steam\steamapps\common\BALLxPIT`, `Balls.exe`가 있는 폴더)에 압축 해제하여 `version.dll`이 `Balls.exe` 옆에 오도록 합니다. zip에는
MelonLoader가 이미 들어 있으므로 따로 설치할 필요가 없습니다. 게임을 실행합니다. 첫 실행은 위와 같이
느리고 소리가 나지 않습니다.

## 모드 제거 {#removing-the-mod}

설치 프로그램의 제거 버튼은 모드와 MelonLoader를 지우고 설정은 `UserData`에 남겨 둡니다.
직접 제거하려면:

`Mods\BallPitAccess.dll`과 `prism.dll`을 삭제합니다. MelonLoader도 제거하려면 게임 폴더에서
`version.dll`과 `MelonLoader`, `Mods`, `Plugins`, `UserData` 폴더를 삭제합니다. 이 모드는 게임 파일을
하나도 바꾸지 않습니다.

## 첫걸음 {#first-steps}

- 언제든 **F1**을 누르면 도움말이 나옵니다: 모든 부분이 들어 있고, 지금 있는 곳에 해당하는 부분부터
  시작합니다. 위아래 화살표로 한 줄씩 읽고, Tab으로 다음 부분으로 이동하고, Esc로 닫습니다.
- **F4**를 누르면 모드 설정이 열리고, 그 안에서 **소리 안내**를 열 수 있습니다: 모든 전투 소리를
  재생하고 그 뜻을 알려 줍니다. 첫 원정 전에 한 번 들어 두면 큰 도움이 됩니다.
- 게임 자체는 키보드를 쓸 때 마우스로 조작하게 되어 있습니다. 이 모드를 쓰면 기지의 방치형 발사대를
  제외하고는 마우스가 전혀 필요 없습니다([알려진 한계](#known-limits) 참고).

## 어디서나 쓰는 키 {#keys-everywhere}

| 키 | 동작 |
|---|---|
| F1 | 도움말(모든 부분, Tab / Shift+Tab으로 부분 사이 이동) |
| F2 | 화면 전체 읽기 |
| F3 | 마지막으로 말한 내용 다시 듣기 |
| F4 | 모드 설정과 소리 안내 |
| F5 | 조준 보조 모드 변경 |
| F6 / F7 | 조준을 왼쪽 / 오른쪽으로 10도 돌리기 |
| F8 | 조준 방향 알려 주기 |
| Ctrl+위 화살표 | 포커스된 항목의 세부 정보 읽기(Ctrl+아래 화살표로 돌아가기) |
| Ctrl+왼쪽 화살표 / Ctrl+오른쪽 화살표 | 세부 정보와 최근 이벤트 사이 전환 |

모드 목록(도움말, 설정, 소리 안내)이 열려 있는 동안에는 게임이 키 입력을 받지 않습니다.

## 메뉴 {#menus}

모든 화면은 **알기 쉬운 순서로 된 목록 하나**입니다: 먼저 선택지, 다음은 버튼, 마지막은 닫기입니다.
이 순서는 화면에서 무엇이 어디에 그려져 있는지와 상관이 없습니다.

| 키 | 동작 |
|---|---|
| 위 / 아래 화살표 | 이전 / 다음 항목 |
| 엔터 | 선택 |
| Tab / Shift+Tab | 화면의 다음 / 이전 그룹 |
| Home / End | 그룹의 첫 / 마지막 항목 |
| 왼쪽 / 오른쪽 화살표 | 목록이나 슬라이더 설정 변경. 층계에서는 난이도 변경 |
| Ctrl+Tab / Ctrl+Shift+Tab | 탭이 있는 화면에서 다음 / 이전 탭 |
| 백스페이스 또는 Esc | 뒤로 |
| Page Up / Page Down | 백과사전의 세트, 층계 목록의 새 게임 플러스 단계 |
| Shift+엔터 | 층계에서: 그 층계의 점수판 열기 |

- 캐릭터에서 엔터를 누르면 그 캐릭터의 선택 버튼으로 이동합니다.
- 안내 튜토리얼이 무언가를 가리키면 포커스가 그곳으로 이동합니다: 엔터를 누르세요.
- 강화 선택지는 숫자까지 함께 읽어 줍니다("10에서 15의 피해를 줍니다").

## 기지 (뉴 볼빌론) {#the-base-new-ballbylon}

| 키 | 동작 |
|---|---|
| 위 / 아래 화살표, 엔터 | 측면 바 버튼: 원정, 채집, 건설, 확장, 재배치, 옵션 |
| Tab / Shift+Tab | 승강기와 건물을 차례로 이동 |
| 건물에서 엔터 | 채집 준비가 되었으면 그 건물을 조준한 채 채집 시작, 아니면 그 건물의 강화 열기 |
| Shift+엔터 | 건물 강화 열기 |
| 승강기에서 엔터 | 승강기 강화 열기(구덩이 아래로, 또는 부상한 볼빌론으로) |
| Delete | 건물 해체 |
| H | 자원과 날짜 |
| J | 채집과 일꾼 |
| K | 기지를 한 칸씩 탐색 |
| I | 건물을 배치하거나 옮길 때: 이 자리가 무엇을 가로막는지 |

- **건설**: 화살표로 건물을 한 칸씩 옮기면 놓을 수 있는지 알려 주고, 엔터로 건설, R로 회전, Home으로
  빈자리로 이동, 백스페이스로 취소합니다.
- **채집**: 건물을 조준한 채로 시작합니다. 엔터로 일꾼을 발사하고, Tab으로 다른 건물을 조준하고,
  왼쪽 / 오른쪽 화살표로 조준을 돌리고, 스페이스를 누르고 있으면 빨라지고, Esc로 나갑니다.
- **공사**: 공사 중이거나 업그레이드 중인 건물도 채집의 Tab 목록에 있습니다. 일꾼이 튕길 때마다 건설이 진행되고, 완성되면 모드가 알려 줍니다. 기지에서 그 건물에 엔터를 누르면 그 건물을 조준한 채로 채집이 시작됩니다.
- **일꾼이 닿을까?** 채집이 건물을 조준하면(Tab, 또는 기지에서 그 건물에 Enter) 모드는 게임이 일꾼을 움직이는 방식 그대로 경로를 따라가 닿는 각도를 고릅니다. "일꾼이 바로 맞힙니다", "일꾼이 벽에 튕겨서 닿습니다", "일꾼이 위로 지나갑니다"(밀밭), 또는 "길이 막혔습니다. 숲이(가) 가로막습니다". 길이 막힌 건물에는 운이 좋아야 닿습니다. 그 건물이나 가로막는 건물을 옮기세요. 왼쪽 / 오른쪽 화살표는 그 선이 무엇에 맞는지 알려 줍니다.
- **채집이 끝나면** 모드는 건설 중인 건물마다 얼마나 진행됐는지 알려 줍니다("유령의 집: 6번 맞음, 40퍼센트에서 55퍼센트"). 게임 자체 요약은 자원만 세기 때문에, 아무것도 채집하지 못하면 일꾼이 건설했어도 "헛수고"라고 나옵니다.
- **확장**: Tab으로 영지를 고르고, 엔터로 구매합니다.
- **재배치**: Tab으로 건물을 고르고, 엔터로 집어 들고, 화살표로 옮기고, 엔터로 내려놓습니다.
- **탐색** (K): 화살표로 한 칸씩 이동하며 그 칸에 무엇이 있는지 알려 줍니다. 빈 칸(오른쪽과 아래로 빈 칸이 몇 개 이어지는지), 크기와 함께 건물, 또는 구매하지 않은 땅. Tab / Shift+Tab은 다음 / 이전 빈 칸으로 이동합니다. K, 백스페이스 또는 Esc로 나갑니다. 열과 행은 건물을 배치할 때와 같습니다.
- 건설 메뉴는 건물마다 차지하는 공간을 알려 주고("가로 3, 세로 2"), 배치를 시작할 때 이름과 크기를 말합니다.
- **건물 배치 또는 이동**: 위치와 함께 무엇에 막혔는지 알려 줍니다("숲에 막힘"). I 키는 일꾼이 이 자리에 닿는지와 어떤 건물을 막거나 벽에 튕겨야만 닿게 만드는지 알려 줍니다. Home은 일꾼이 곧바로 맞힐 수 있고 아무것도 막지 않는 가장 좋은 빈자리를 찾아 건물을 돌려 맞춥니다. R을 누르면 새 모양을 알려 줍니다. 유령의 집처럼 직사각형이 아닌 건물도 있습니다("왼쪽 위 모서리가 비어 있음"). 재배치할 때도 건물을 돌릴 수 있습니다.
- **탐색**: Page Down / Page Up으로 다음 / 이전 건물로 이동하며 위치, 크기, 모양을 알려 줍니다.

## 전투 {#battle}

### 게임 자체의 키

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 스페이스 | 발사(누르고 있기) |
| F | 자동 발사 켜기 / 끄기 |
| E | 레벨 업이 준비되면 열기 |
| = / - (이퀄 / 마이너스) | 게임 속도 빠르게 / 느리게(일부 키보드 배열에는 없습니다: 아래 모드 키 Num + / Num -를 쓰세요) |
| Esc | 일시 정지 |

### 모드 키

| 키 | 동작 |
|---|---|
| 왼쪽 / 오른쪽 화살표 | 조준을 직접 5도씩 돌리기 |
| 위 화살표 | 조준을 조준 보조에게 돌려주기 |
| 아래 화살표 | 조준 방향 알려 주기 |
| Shift(누르고 있기) | 받기 보조([보조 기능](#assists) 참고) |
| 1부터 7, 0 | 소리 필터([소리 필터](#sound-filters-number-keys) 참고) |
| H | 체력과 상태 이상 |
| U | 상태 효과와 남은 초, 이동할 수 있는지, 못 한다면 그 이유(빙결, 공격에 밀려남, 적 전진 중). 빙결이 풀리면 "다시 이동할 수 있습니다"라고 알려 줍니다 |
| J | 적과 보스 |
| K | 내 위치 |
| G | 게임 속도 |
| L | 레벨, 시간, 웨이브, 얻은 기어 |
| B | 내 볼과 패시브 |
| P | 필드의 아이템 |
| N | 위험 요소(투사체, 레이저, 폭탄, 바닥) |
| Q | 방금 그 소리는? 지금 나는 소리와 최근 몇 개의 소리를 각각의 뜻과 방향과 함께 알려 줌 |
| M | 전투 지도(일시정지) |
| Num + / Num - | 게임 속도 빠르게 / 느리게, 어떤 키보드 배열에서든 |

모든 모드 키는 바꿀 수 있습니다: [키 바꾸기](#changing-keys) 참고.

전투 중에 말해 주는 것: 시작할 때의 층계, 보스와 보스 체력(75, 50, 25퍼센트), 피해와 체력, 상태 이상,
특수 아이템이 떨어졌을 때, "레벨 업 준비됨, E 키를 누르세요", 원정의 끝.

**보스**: J는 보스의 실제 체력을 알려 줍니다. 게임의 보스 바와 같습니다. 약점에만 피해를 받는 보스도 있습니다. 해골 왕은 몸에 피해를 줄 수 없고 머리의 왕관만 약점인데, 몸이 앞쪽에서 왕관을 막아서 공은 벽에 튕긴 뒤에 닿습니다. J는 약점의 위치를 알려 주고, 조준 보조는 그곳을 노립니다.

**전투 지도(일시정지)**: M 키는 전투 지도를 열고 게임을 일시정지합니다. 화살표로 필드를 한 칸씩 걸으며 무엇이 있는지 읽습니다: 적과 체력, 내 볼, 탄, 레이저, 폭탄, 바닥 위험, 아이템. Control과 위쪽 화살표는 적이 하는 일, 상태, 상태 효과를 읽습니다. Tab은 가까운 적부터 적에서 적으로 이동하고, Page Down은 다른 것으로, Home은 나에게 돌아가고, End는 모두 셉니다. Enter는 적에게 조준을 고정합니다. 적이 죽으면 조준은 가장 가까운 적으로 돌아갑니다. Delete는 고정을 해제합니다. M 또는 Escape로 지도를 닫으면 전투가 계속됩니다.

## 전투 소리 {#battle-sounds}

모든 소리에 세 가지 규칙이 적용되며, 언제나 내 영웅을 기준으로 합니다:

- **방향**: 소리는 그 대상이 있는 곳에서 들립니다. 내 왼쪽에 있으면 왼쪽, 오른쪽에 있으면 오른쪽, 바로
  앞에 있으면 가운데에서 들립니다.
- **음높이**: 높을수록 가깝습니다.
- **먹먹한** 소리는 내 뒤에 있다는 뜻입니다.

계속 움직이는 것(내 볼, 적의 투사체)은 그것을 따라가는 **연속 소리**이고, 단계적으로 바뀌는 것(전진하는
적, 바닥에 놓인 아이템)은 짧은 소리입니다.

| 소리 | 뜻 |
|---|---|
| 손북 소리 | 적. 높고 빠를수록 가깝습니다. 적이 움직이면 가까운 적들이 번갈아 울리고, 변화가 없는 동안에는 가장 가까운 적만 울립니다. |
| 크고 낮은 북 | 보스. 보스가 등장할 때는 북, 징, 뿔피리 소리가 납니다. |
| 으르렁 소리 | 적이 곧 나에게 닿습니다. |
| 높아지는 끼잉 소리 | 적이 공격을 준비합니다. 적이 있는 쪽에서 들립니다. |
| **굴러가는 웅웅 소리**(연속) | 받을 수 있는 볼. **볼이 있는 곳**에서 들리고 **볼이 가까워질수록 높아지므로**, 볼이 어디로 향하는지 들을 수 있습니다. 볼이 내 줄에 다가올수록 빠르게 맥박치며, 볼이 아직 적에게 튕길 수 있는 동안에는 소리가 작습니다. |
| 딸깍 소리 | 볼이 떨어질 곳에 서 있습니다: 그대로 있으세요. |
| 글러브 턱 소리 | 볼을 받았습니다. |
| 가라앉는 둔탁한 쿵 소리 | 볼을 놓쳤습니다. |
| 철컥 장전 소리 | 볼이 모두 돌아왔습니다: 발사할 수 있습니다(자동 발사 중에는 나지 않음). |
| 유리 팅 소리 | 걸어가서 주울 경험치 보석, 골드, 자원: 가장 가까운 것, 또는 조금 더 먼 곳의 무더기. 저절로 모이지 않습니다. |
| 칼림바 반짝 소리 | 특수 아이템: 융합 원자로, 설계도, 알, 기어, 체력, 자석, 폭탄, 보석 주머니. |
| **바람 같은 휘파람 소리**(연속) | 내 근처를 나는 적의 투사체. 다가올수록 높아집니다. 나를 맞힐 때는 더 커집니다. |
| 휙 하고 딱 소리 | 투사체가 나를 맞힙니다. 투사체가 있는 곳에서 들립니다: 날아오는 길에서 비키세요. |
| 지잉 하는 전기 소리 / 전기 지직 소리 두 번 | 레이저가 조준 중 / 내가 레이저 선 위에 있음. 둘 다 레이저에서 들립니다: 선 밖으로 비키세요. |
| 떨어지는 휘익 소리 / 도화선 치익 소리 | 근처에 폭탄이 떨어짐 / 폭탄이 내 위에 떨어짐. 둘 다 폭탄이 떨어질 곳에서 들립니다: 그곳을 피하세요. |
| 철퍽 소리 | 바닥 위험 요소를 밟았습니다(이름을 말해 줍니다). |
| 펀치 소리 / 꿀꺽 소리 | 피해 / 회복. |
| 심장 박동 | 체력 부족. 매우 낮으면 더 빨라집니다. |
| 어지러운 울렁 소리 | 상태 이상에 걸렸습니다. |
| 올라가는 종소리 두 음 | 레벨 업 준비 완료(E를 누르세요). |
| 나무 두드리는 소리 | 경기장 옆 가장자리(메뉴 목록의 끝에서도 납니다). |
| 금속 두드리는 소리 | 내 이동 구역의 앞이나 뒤 끝. |
| 스위치 딸깍 소리 | 조준 보조가 다른 대상으로 바꿨습니다. 새 대상 쪽에서 들립니다. 자동 사격 중에는 처치 후에 울리지 않습니다. |

이 소리들은 모두 **F4 → 소리 안내**에서 들어 볼 수 있으며, 왼쪽 / 오른쪽 화살표로 각 방향에서 들을 수
있습니다. 전투 중에는 **Q**가 방금 들은 소리를 알려 줍니다.

## 소리 필터 (숫자 키) {#sound-filters-number-keys}

전투 중에 숫자 키로 소리 그룹을 끄거나 켜서 집중할 수 있습니다. 게임은 이 키들을 전혀 쓰지 않습니다.

| 키 | 그룹 |
|---|---|
| 1 | 적: 북, 으르렁, 공격 준비, 보스 등장 |
| 2 | 볼: 굴러가는 웅웅 소리, 딸깍, 받기, 놓침, 장전 소리 |
| 3 | 보상: 경험치 보석, 골드, 자원, 특수 아이템 |
| 4 | 투사체와 위험 요소 |
| 5 | 경기장 가장자리 |
| 6 | 내 체력: 피해, 회복, 심장 박동, 상태 |
| 7 | 조준 보조 클릭 |
| 0 | 모두 다시 켜기 |

- 각 숫자는 다른 그룹과 상관없이 자기 그룹만 켜고 끕니다.
- **Ctrl+숫자**는 그 그룹만 남깁니다. 예: 적과 보상만 들으려면 Ctrl+1, 그다음 3.
- 선택한 설정은 다음 실행 때도 유지됩니다. 꺼진 소리가 있는 채로 전투가 시작되면 모드가 무엇이
  꺼져 있는지 알려 줍니다.
- 소리를 꺼도 바뀌는 것은 소리뿐입니다: H, J, P, N 키는 그대로 응답하고, 받기 보조도 그대로 피합니다.

## 보조 기능 {#assists}

보조 기능이 하는 일은 모두 귀로 듣고 직접 할 수도 있습니다. 보조 기능은 원할 때 쓰라고 있는 것입니다.

- **조준 보조**(F5로 모드 변경): 가장 가까운 적(기본값), 가장 강한 적, 내 앞에 있는 적, 고정 각도를
  대신 조준하거나, 꺼짐(마우스)으로 둘 수 있습니다. 화살표로 미세 조정합니다. 다른 적에게 가려지지 않은 부분을 조준하고, 영웅이 쏠 수 없는 각도의 적은 건너뛰며, 기본 모드에서는 다른 적이 곧 닿을 상황이 아니면 보스를 먼저 노립니다.
- **받기 보조**(Shift 누르고 있기): 영웅이 내려오는 다음 볼 아래로 걸어갑니다. 오는 볼이 없으면 가장
  가까운 보석이나 아이템으로 걸어가고, 투사체가 곧 맞을 것 같으면 먼저 피합니다. W / S로는 여전히
  앞뒤로 움직일 수 있고, A / D를 누르면 언제나 직접 조작으로 돌아옵니다. F4에서 꺼짐, "Shift 누르고
  있기"(기본값), 자동 중에서 고를 수 있습니다. 다쳤을 때는 회복 아이템을 먼저 주우러 갑니다.

## 모드 설정 (F4) {#mod-settings-f4}

위 / 아래 화살표로 이동하고, 왼쪽 / 오른쪽 화살표나 엔터로 바꾸고, Esc로 닫습니다. 설정은 저장됩니다.

- 조준 보조 모드
- 받기 보조: 꺼짐, Shift 누르고 있기, 자동
- 안내음 켜기 / 끄기, 안내음 음량
- 적 레이더, 볼 소리, 경기장 가장자리, 투사체와 위험 요소(켜기 / 끄기)
- 아이템 소리: 꺼짐, 특수 아이템만, 모두
- 체력 소리, 조준 보조 클릭(켜기 / 끄기)
- 포커스 시 강화 설명 읽기
- 컨트롤러
- 키(엔터로 열기): [키 바꾸기](#changing-keys) 참고
- 소리 안내(엔터로 열기)
- 디버그 로그
- 전투 기록 (기본값 꺼짐): 모든 전투를 `UserData\BallPitAccess\telemetry.tsv`에 기록합니다 (소리 조정용)

## 키 바꾸기 {#changing-keys}

**F4 → 키**에는 모든 모드 키와 지금 지정된 키가 나옵니다. 위 / 아래 화살표로 고르고, **엔터**를 누른 다음 새
키를 누릅니다(Esc로 취소). **Delete**는 기본 키로 되돌리고, 마지막 줄은 모든 키를 되돌립니다. 새 키가 이미 다른
모드 동작에 쓰이고 있으면 두 키가 서로 바뀌고, 모드가 다른 동작이 어디로 옮겨졌는지 알려 줍니다. 메뉴나 게임에
필요한 키(화살표, 엔터, Tab, Esc, 백스페이스, 스페이스, W A S D F E R X)는 쓸 수 없습니다. F1 도움말의 끝에서
지금 설정된 키를 알려 줍니다.

## 컨트롤러 {#controller}

- Xbox 버튼 기준입니다; PlayStation이나 Switch 컨트롤러는 게임에 Steam Input을 켜면 작동합니다
- 전투 밖에서는 방향 패드나 왼쪽 스틱이 화살표처럼 움직이고, A는 엔터, B는 뒤로입니다
- X와 Y는 첫 항목과 마지막 항목으로 갑니다; 건물을 배치하는 중에는 X가 들어갈 자리를 찾고 Y가 회전시킵니다
- RB와 LB는 Tab과 Shift Tab, RT와 LT는 화면의 탭을 바꿉니다
- Start는 게임의 일시 정지입니다
- 전투에서는 스틱, 트리거, 버튼을 게임이 씁니다
- 방향 패드 위는 적, 아래는 체력, 왼쪽은 상태, 오른쪽은 진행 상황을 말합니다
- 잡으려면 왼쪽 스틱을 눌러 유지하세요, Shift와 같습니다
- 오른쪽 스틱을 그대로 두면 조준 보조가 대신 조준하고, 움직이면 직접 조준합니다
- 더 많은 기능은 View를 누른 채로: A 도움말, B 모드 설정, X 화면 읽기, Y 반복, Start 조준 모드 변경
- View와 LB, RB는 검토 목록의 이전 줄과 최근 줄을 읽고, View와 스틱 클릭은 세부 정보와 이벤트를 전환합니다
- 전투에서 View와 방향 패드: 위 위험, 아래 장비, 왼쪽 아이템, 오른쪽 마지막 소리; View와 LT, RT는 게임 속도를 낮추고 높입니다
- 기지에서 View와 방향 패드: 위 수확, 아래 자원, 왼쪽 탐색 모드
- 메뉴에서 View와 LT, RT는 Page Up과 Page Down입니다

전투 중 오른쪽 스틱을 누르면 전투 지도가 열립니다. 일시정지 메뉴에서는 보기와 방향 패드 오른쪽입니다. 지도에서는 방향 패드로 걷고, RB와 LB로 적 사이를 이동하고, A로 조준을 고정하고, B로 닫습니다.

## 첫 원정을 위한 팁 {#tips-for-a-first-run}

- **볼을 받으세요.** 받은 볼은 곧바로 다시 발사할 수 있지만, 놓친 볼은 돌아오는 데 2~3초가 걸립니다.
  딸깍 소리가 들릴 때까지 굴러가는 웅웅 소리를 따라간 다음, 그 자리에 있으세요.
- **경험치 보석을 주우세요.** 저절로 모이지 않습니다. 유리 팅 소리를 따라가세요. 먹먹하게 들리면 내
  뒤에 있는 것입니다.
- **먼저 살아남으세요.** 원정 초반에는 피해량보다 살아남는 것이 더 중요합니다.
- 레벨 업에서 제안하면 볼을 **융합하고 진화시키세요**: 선택지에 "융합"이나 "진화"라고 나옵니다.
- **보스전에서는 Num -(또는 게임의 마이너스 키)로 속도를 늦추세요.** 빠른 속도에서 보스가 등장하면 모드가 알려 줍니다.
- 죽는 것은 당연한 일입니다: 가지고 돌아온 골드로 뉴 볼빌론을 짓고, 건물은 이후의 모든 원정을 더
  강하게 만들어 줍니다.

## 알려진 한계 {#known-limits}

- 기지의 방치형 발사대는 아직 마우스가 필요합니다.
- 점수판과 Twitch 투표는 기본적인 수준으로만 읽어 줍니다. 크레딧은 건너뛸 수 없습니다.
- 모드 설정은 게임 자체의 옵션 화면이 아니라 F4에 있습니다.
- 영어와 스페인어가 아닌 언어로 된 모드 자체의 문구는 아직 원어민의 검토 없이 번역되었습니다. 수정
  제안을 환영합니다. 게임에서 오는 이름(건물, 볼, 적, 강화)은 항상 게임 자체의 번역을 그대로 씁니다.
- 소리 음량, 반복 속도, 받기 판정 폭은 아직 플레이어와 함께 조정하지 않았습니다.

## 문제 신고 {#reporting-a-problem}

게임 폴더에 있는 유용한 파일:

- `UserData\BallPitAccess\speech.log`: 모드가 말한 모든 내용.
- `MelonLoader\Latest.log`: 모드의 로그(오류, 화면, 받기와 놓침).
- 전투 중에 **Ctrl+Shift+D**를 누르면 `UserData\BallPitAccess\threats.txt`(적, 볼, 투사체, 아이템과 그
  위치)를 기록하고, 열려 있는 화면의 목록을 `Latest.log`에 기록합니다: 소리가 엉뚱한 방향을 가리키거나
  메뉴가 잘못된 순서로 읽힐 때 유용합니다.
- `UserData\BallPitAccess\telemetry.tsv`: F4 → 전투 기록을 켰다면. 전투의 모든 소리, 적, 공, 탄이
  담깁니다. 소리를 따라가기 어려울 때 가장 큰 도움이 됩니다.

무엇을 했는지, 무엇을 들었는지, 무엇을 기대했는지 알려 주세요.
