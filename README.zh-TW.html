BALL x PIT Access

這是一個讓視障玩家也能遊玩 BALL x PIT（Kenny Sun / Devolver Digital）的模組。它會透過你的螢幕閱讀器 讀出每一個選單，讓你只用鍵盤就能玩完整個遊戲，並把戰場變成聲音：敵人、你的戰球、敵方子彈、XP 寶石和特殊道具 都有各自的音效，從它們在你身邊的那一側傳來。

版本 0.5.0，適用遊戲版本 1.308，包含「崛起波比倫」（Risen Ballbylon）DLC。模組會說遊戲提供的所有語言， 並跟隨遊戲的語言設定。

你需要什麼

  • Windows 版（Steam）的 BALL x PIT，版本 1.308。
  • 螢幕閱讀器：測試過的是 NVDA。Prism 語音函式庫支援的其他螢幕閱讀器（JAWS、朗讀程式、SAPI 語音） 應該也能使用。
  • MelonLoader 0.7.3（x64），模組載入器。免費，可從它官方的 GitHub 發行頁面下載。
  • 耳機或立體聲喇叭：在戰鬥中，左右聲道非常重要。

安裝

使用安裝程式（最簡單）：從最新版本下載 BallPitAccessibilityInstaller.exe 並執行。 它會透過 Steam 找到遊戲，安裝 MelonLoader 0.7.3、Prism 語音函式庫和模組，之後也能更新或移除它們。接著啟動 遊戲：第一次啟動需要幾分鐘，MelonLoader 準備遊戲檔案時沒有聲音；之後你的螢幕閱讀器就會開始說話。

手動安裝：從同一頁面下載 BallPitAccess-vX.Y.Z.zip，把全部內容解壓縮到遊戲資料夾（預設為 C:\Program Files (x86)\Steam\steamapps\common\BALLxPIT，也就是含有 Balls.exe 的資料夾），讓 version.dll 位於 Balls.exe 旁邊。壓縮檔已包含 MelonLoader，不需要另外安裝。啟動遊戲；第一次啟動和上面一樣，較慢且沒有聲音。

移除模組

安裝程式的「解除安裝」按鈕會移除模組和 MelonLoader，並保留你在 UserData 中的設定。手動移除：

刪除 Mods\BallPitAccess.dll 和 prism.dll。如果也要移除 MelonLoader，請從遊戲資料夾刪除 version.dll 以及 MelonLoader、Mods、Plugins、UserData 這幾個資料夾。模組不會修改任何遊戲檔案。

第一步

  • 隨時按 F1 打開說明：包含所有部分，從你目前所在位置的那一部分開始。 上下方向鍵一行一行閱讀，Tab 跳到下一個部分，Esc 關閉。
  • 按 F4 打開模組設定，並在裡面打開音效指南：它會播放每個戰鬥音效並說明意思。 在第一局之前先聽一遍，會很有幫助。
  • 用鍵盤玩的話，遊戲本身是靠滑鼠操作的；有了這個模組，除了基地裡的閒置發射器之外，你都不需要滑鼠 （請見已知限制）。

戰鬥音效

每個音效都遵守三個規則，而且一律以你的角色為準：

  • 方向：音效從它所代表的東西所在的位置傳來：在你左邊就從左邊傳來，在你右邊就從右邊傳來，在正前方就在正中間。
  • 音調：越高代表越近。
  • 悶悶的聲音代表在你後方。

一直在移動的東西（你的戰球、敵方子彈）是會跟著它們的持續音效；一步一步改變的東西 （前進的敵人、掉在地上的道具）是短音效。

音效 意思
手鼓 敵人。音越高越快 = 越近。敵人移動時，最近的幾個輪流響起；沒有變化時只響最近的一個。
大而低沉的鼓 魔王。魔王登場時會有鼓聲、鑼聲和號角。
咆哮聲 有敵人快要碰到你。
上升的嗚嗚聲 敵人正在蓄力攻擊，聲音在它那一側。
滾動的嗡嗡聲（持續） 你能接的戰球。它從戰球所在的位置傳來，戰球離你越近，音調越高，讓你聽出它往哪裡飛；戰球越接近你這一列脈動越快；戰球還可能從敵人身上反彈時，聲音比較小。
喀嗒聲 你站在戰球的落點上：待在那裡。
手套的悶響 接到戰球。
沉悶下沉的撞擊聲 有一顆戰球從你身邊漏掉了。
槍架聲 你的戰球都回來了：可以發射（開啟自動射擊時不會出現）。
玻璃叮聲 應走去撿取的經驗水晶、金幣或資源：最近的一個，或稍遠處的一堆。它們不會自動收集。
卡林巴琴的閃亮聲 特殊道具：融合反應器、藍圖、蛋、零件、生命值、磁鐵、炸彈、寶石袋。
輕飄的哨音（持續） 飛到你附近的敵方子彈，越靠近音調越高。會打中你時聲音更大。
咻的一聲加上爆裂聲 子彈會打中你；聲音來自子彈：閃開它的路線。
電流嗡嗡聲 / 兩下滋滋聲 有雷射正在瞄準 / 你在它的直線上；兩者都來自雷射：離開這條直線。
下墜的哨音 / 引信嘶嘶聲 附近有炸彈正在落下 / 它會落在你身上；兩者都來自它的落點：遠離它。
啪嘰聲 你踩到地面危險（會說出它的名稱）。
一拳 / 咕嚕聲 受到傷害 / 回復生命值。
心跳聲 生命值低；非常低時更快。
暈眩的搖晃聲 你中了狀態效果。
兩個往上的鈴聲 可以升級了（按 E）。
木頭敲擊聲 場地的側邊（也是選單清單的盡頭）。
金屬敲擊聲 你活動區域的前方或後方界線。
開關喀嗒聲 瞄準輔助切換到了另一個目標，在新目標那一側響起。開啟自動射擊時，擊殺後不響。

這些音效全都可以在 F4 → 音效指南中聽到，用左右方向鍵可以聽它在每一側的聲音。 戰鬥中，Q 會說出你剛才聽到的音效。

音效篩選（數字鍵）

在戰鬥中，數字鍵可以把一組音效靜音或取消靜音，讓你專心。遊戲本身沒有使用這些按鍵。

按鍵 音效組
1 敵人：鼓聲、咆哮聲、蓄力聲、魔王登場
2 戰球：滾動的嗡嗡聲、喀嗒聲、接到、漏接、槍架聲
3 獎勵：XP 寶石、黃金、資源、特殊道具
4 子彈和危險
5 場地邊緣
6 你的生命值：受傷、治療、心跳、狀態
7 瞄準輔助喀嗒聲
0 全部重新開啟
  • 每個數字鍵只切換自己那一組，和其他組無關。
  • Ctrl+數字鍵只保留那一組。例如只保留敵人和獎勵 = 先按 Ctrl+1，再按 3。
  • 你的選擇會保留到下次遊玩。戰鬥開始時如果有音效被靜音，模組會說出哪些被靜音了。
  • 靜音只影響音效：H、J、P、N 鍵仍然會回答，接球輔助也仍然會閃避。

輔助功能

輔助功能做的每一件事，你也都可以靠耳朵自己做到；輔助功能是在你需要時給你用的。

  • 瞄準輔助（F5 切換模式）：幫你瞄準最近的敵人（預設）、最強的敵人、你正前方的敵人、固定角度， 或關閉（用滑鼠）。方向鍵可以微調。它會瞄準敵人沒被其他敵人擋住的部位，略過英雄無法射擊的角度上的敵人；在預設模式下，除非有別的敵人馬上就要碰到你，否則優先打魔王。
  • 接球輔助（按住 Shift）：角色會走到下一顆落下的戰球下方；沒有戰球飛來時，會走到最近的 XP 寶石或道具； 如果有子彈快要打中你，它會先閃開。W / S 仍然可以讓你前進和後退，A / D 永遠會接手控制。在 F4 中可以設為 關閉、「按住 Shift」（預設）或自動。你受傷時，它會先去撿回復道具。

模組設定（F4）

上下方向鍵移動，左右方向鍵或 Enter 變更，Esc 關閉。設定會自動儲存。

  • 瞄準輔助模式
  • 接球輔助：關閉、按住 Shift、自動
  • 音效提示開啟 / 關閉、提示音量
  • 敵人雷達、戰球音效、場地邊緣、子彈和危險（開啟 / 關閉）
  • 道具音效：關閉、只有特殊道具、全部
  • 生命值音效、瞄準輔助喀嗒聲（開啟 / 關閉）
  • 焦點移到升級時讀出說明
  • 按鍵（按 Enter 打開）：請看更改按鍵
  • 音效指南（按 Enter 打開）
  • 除錯記錄
  • 記錄戰鬥（預設關閉）：每場戰鬥都會寫入 UserData\BallPitAccess\telemetry.tsv，用於調整聲音

更改按鍵

F4 → 按鍵列出每個模組按鍵和它目前對應的鍵。上下方向鍵選擇，按 Enter 後再按新的鍵（Esc 取消）， Delete 恢復預設按鍵，最後一行把所有按鍵都恢復。如果新的鍵已經屬於另一個模組動作，兩者會互換，模組會說出 另一個動作換到了哪裡。選單或遊戲需要的鍵（方向鍵、Enter、Tab、Esc、Backspace、空白鍵、W A S D F E R X） 不能使用。F1 說明的最後會列出目前設定的按鍵。

第一局的小訣竅

  • 接住你的戰球。 接住的戰球可以馬上再發射；漏接的要 2 到 3 秒才會回來。 跟著滾動的嗡嗡聲走，直到聽見喀嗒聲，然後待在那裡。
  • 撿起你的 XP 寶石。 它們不會自動收集。跟著玻璃叮聲走；聲音悶悶的代表在你後方。
  • 先求生存。 在一局的前期，活下來比造成傷害更重要。
  • 升級時有機會的話，就融合和進化你的戰球：選項上會寫「融合」或「進化」。
  • 遇到魔王時，用 Num -（或遊戲本身的減號鍵）放慢速度。如果魔王出現時遊戲速度很快，模組會提醒你。
  • 死掉是很正常的：你帶回來的黃金可以用來建設新球比倫，而建築會讓之後的每一局都更強。

已知限制

  • 基地裡的閒置發射器仍然需要滑鼠。
  • 排行榜和 Twitch 投票只會用基本的方式讀出。開發人員名單無法跳過。
  • 模組設定在 F4，不在遊戲本身的選項畫面裡。
  • 除了英文和西班牙文之外，其他語言（包括中文）的模組文字都還沒有經過母語人士審閱。歡迎提供修正。 遊戲中的名稱（建築、戰球、敵人、升級）一律來自遊戲本身的翻譯。
  • 音效音量、頻率和接球範圍都還沒有和玩家一起調整過。

回報問題

有用的檔案，都在遊戲資料夾裡：

  • UserData\BallPitAccess\speech.log：模組說過的所有內容。
  • MelonLoader\Latest.log：模組的記錄檔（錯誤、畫面、接到和漏接的戰球）。
  • 在戰鬥中，Ctrl+Shift+D 會寫出 UserData\BallPitAccess\threats.txt（敵人、戰球、子彈、道具及它們的位置）， 並把目前畫面的清單寫進 Latest.log：當某個音效指錯方向，或某個選單的讀出順序不對時很有用。
  • UserData\BallPitAccess\telemetry.tsv：如果你開啟了 F4 → 記錄戰鬥。包含戰鬥中的每個聲音、敵人、彈珠和 子彈。聲音難以分辨時最有幫助。

請說明你做了什麼、聽到了什麼，以及你原本預期會怎樣。
