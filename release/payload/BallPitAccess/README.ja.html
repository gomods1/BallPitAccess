BALL x PIT Access

BALL x PIT（Kenny Sun / Devolver Digital）を、目が見えなくても遊べるようにするMODです。すべてのメニューを スクリーンリーダーで読み上げ、ゲーム全体をキーボードで操作できるようにし、戦場を音に変えます。敵、自分のボール、 敵の弾、経験値ジェム、特殊アイテムには、それぞれ専用の音があり、あなたから見てその方向から聞こえます。

バージョン0.7.0、ゲームバージョン1.308用で、DLC「昇天のボルビロン」にも対応しています。MODはゲームが対応して いるすべての言語で話し、ゲームの言語設定に従います。

状態：初期のテスト版です。 メニュー、拠点、最初の数回のランはMODを使ってプレイ済みです。戦闘の音と 最新の部分（ボールの連続音、キャッチアシスト、サウンドフィルター）は、まだプレイヤーと一緒に調整していません。 うまく動く点と動かない点をぜひ報告してください（問題の報告を参照）。

必要なもの

  • Windows版（Steam）のBALL x PIT、バージョン1.308。
  • スクリーンリーダー：テスト済みなのはNVDAです。Prism音声ライブラリが対応しているほかのもの（JAWS、ナレーター、 SAPI音声）も動くはずです。
  • MODローダーのMelonLoader 0.7.3（x64）。無料で、公式のGitHubリリースページから入手できます。
  • ヘッドホンまたはステレオスピーカー：戦闘では左右の聞き分けがとても重要です。

インストール

インストーラーを使う（いちばん簡単）：最新リリースから BallPitAccessibilityInstaller.exe をダウンロードして実行します。Steamからゲームを見つけ、MelonLoader 0.7.3、音声ライブラリPrism、MODをインストールし、あとから更新や削除もできます。そのあとゲームを起動します。 初回起動は数分かかり、MelonLoaderがゲームのファイルを準備している間は音が出ません。そのあとスクリーン リーダーが話し始めます。

手動で：同じページから BallPitAccess-vX.Y.Z.zip をダウンロードし、中身をすべてゲームフォルダー （初期設定では C:\Program Files (x86)\Steam\steamapps\common\BALLxPIT、Balls.exe が入っているフォルダー）に展開して、version.dll が Balls.exe の隣に 来るようにします。zipにはMelonLoaderが含まれているので、別途インストールする必要はありません。ゲームを起動 します。初回起動は上と同じく時間がかかり、音が出ません。

MODの削除

インストーラーの「アンインストール」ボタンはMODとMelonLoaderを削除し、設定は UserData に残します。 手動で行う場合：

Mods\BallPitAccess.dll と prism.dll を削除します。MelonLoaderも削除するには、ゲームフォルダーから version.dll と、MelonLoader、Mods、Plugins、UserData の各フォルダーを削除します。MODはゲームの ファイルを一切変更しません。

はじめに

  • いつでも F1 でヘルプを開けます。すべてのセクションが、今いる場所のセクションから順に並んでいます。 上下矢印で1行ずつ読み、Tabで次のセクションへ移動し、Escで閉じます。
  • F4 でMODの設定を開き、その中のサウンドガイドを開いてください。戦闘のすべての音を再生し、その意味を 読み上げます。最初のランの前に一度聞いておくと、とても役に立ちます。
  • ゲーム自体は、キーボードではマウス操作が前提です。MODを使えば、拠点にある放置用の発射台を除いて、マウスは まったく必要ありません（既知の制限を参照）。

拠点（ニュー・ボルビロン）

キー 動作
上矢印 / 下矢印、Enter サイドバーのボタン：バトル、回収、建築、拡張、配置換え、オプション
Tab / Shift+Tab 昇降機と建物を順に移動
建物の上でEnter 準備ができていれば、その建物を狙って回収を開始。そうでなければアップグレードを開く
Shift+Enter 建物のアップグレードを開く
昇降機の上でEnter 昇降機のアップグレードを開く（ピットを下る、または昇天のボルビロンへ）
Delete 建物を解体
H 資源と日数
J 回収と作業者
K 拠点を1マスずつ探索
  • 建築：矢印キーで建物を1マス動かし、置けるかどうかを読み上げます。Enterで建築、Rで回転、Homeで空いている 場所へ移動、BackSpaceでキャンセルします。
  • 回収：建物を狙った状態で始まります。Enterで作業者を送り出し、Tabで別の建物を狙い、左右矢印でエイムを回し、 スペース長押しで加速、Escで終了します。
  • 建設：建設中や改良中の建物も回収のTabリストに入ります。作業者が跳ね返るたびに建設が進み、完成するとModが知らせます。拠点でその建物にEnterを押すと、その建物を狙って回収が始まります。
  • 作業者は届く？ 回収で建物を狙うと（Tab、または拠点でその建物にEnter）、Modはゲームと同じ動き方で作業者の通り道をたどり、届く角度を選びます。「作業者が直接当たります」「作業者が壁に跳ね返って届きます」「作業者が上を通ります」（小麦畑）、または「通り道がありません。森が邪魔です」。通り道のない建物には偶然でしか届きません。その建物か、邪魔な建物を動かしてください。左右矢印で、その線が何に当たるかを読み上げます。
  • 回収のあと、Modは建設中の各建物が得たものを読み上げます（「幽霊屋敷：6回命中、40パーセントから55パーセント」）。ゲーム自体のまとめは資源しか数えないため、何も回収しなかったときは作業者が建設していても「無駄骨」と表示します。
  • 拡張：Tabで区画を選び、Enterで購入します。
  • 配置換え：Tabで建物を選び、Enterで持ち上げ、矢印キーで動かし、Enterで置きます。
  • 探索（K）：矢印で1マスずつ進み、そこに何があるかを読み上げます。空き（右と下に空きマスがいくつ続くか）、建物とその大きさ、または未購入の土地。Tab / Shift+Tabで次 / 前の空きマスへ。K、Backspace、Escで終了。列と行は建物を置くときと同じです。
  • 建設メニューでは各建物が使う広さ（「幅3、高さ2」）を読み上げ、配置の開始時に名前と大きさを言います。

ボス：Jはボスの本当の体力を読み上げます。ゲームのボスバーと同じです。弱点にしかダメージを受けないボスもいます。スケルトンキングは体にダメージを与えられず、頭の王冠だけが弱点で、体が正面から王冠を守っているため、ボールは壁に跳ね返ってから届きます。Jは弱点の位置を読み上げ、エイムアシストはそこを狙います。

戦闘の音

すべての音に共通する3つのルールがあります。どれも、あなたの主人公から見た位置です。

  • 方向：音は、それが示すものがある場所から聞こえます。左にあれば左、右にあれば右、真っすぐ前なら真ん中です。
  • 高さ：高い音ほど近くです。
  • こもった音は、後ろにあることを示します。

常に動いているもの（自分のボール、敵の弾）は、それを追いかける連続音です。段階的に変わるもの（前進してくる敵、 床に落ちているアイテム）は短い音です。

音 意味
ハンドドラム 敵。高く速いほど近い。敵が動くと近い敵から順に鳴り、何も変わらない間は最も近い敵だけが鳴ります。
大きく低いドラム ボス。登場時はドラム、どら、ホルン。
うなり声 敵がもうすぐあなたに届きます。
上がっていく甲高い音 敵が攻撃の準備をしています。その敵の方向から聞こえます。
転がるようなハム音（連続） キャッチできるボール。ボールのある場所から聞こえ、ボールが近づくほど高くなるので、どこへ向かっているかがわかります。ボールが手元に迫るほど速く脈打ち、まだ敵に跳ね返る可能性があるうちは小さく鳴ります。
カチッという音 ボールの落下地点に立っています。そのまま待ってください。
グローブのドスッという音 ボールをキャッチ。
沈んでいく鈍い音 ボールを取り逃しました。
銃のラックの音 ボールが戻りました。発射できます（自動攻撃中は鳴りません）。
ガラスのチンという音 歩いて取りに行く経験値クリスタル、ゴールド、資源：最も近いもの、または少し先にある固まり。自動では集まりません。
カリンバのきらめく音 特殊アイテム：融合リアクター、設計図、タマゴ、歯車、体力回復、マグネット、ボム、ジェム袋。
空気のような口笛（連続） 近くを飛ぶ敵の弾。近づくほど高くなります。当たるときは大きくなります。
シュッという音とバチッという音 弾が当たります。弾のある方向から聞こえます：弾の進路からよけてください。
電気のハム音 / 2回のバチバチ音 レーザーが狙いを定めている / その射線上にいます。どちらもレーザーから聞こえます：射線の外へ出てください。
落ちていく口笛 / 導火線のシューという音 近くに爆弾が落ちてくる / 自分の上に落ちます。どちらも爆弾の落ちる地点から聞こえます：そこから離れてください。
グチャッという音 床の危険を踏みました（その名前が読み上げられます）。
パンチの音 / ゴクッという音 ダメージ / 回復。
心音 体力低下。非常に低いと速くなります。
ふらふらと揺れる音 ステータス効果を受けました。
上がっていく2つのベルの音 レベルアップの準備ができました（Eを押してください）。
木をたたく音 アリーナの横の端（メニューのリストの端でも鳴ります）。
金属をたたく音 移動エリアの前端または後端。
スイッチのカチッという音 照準アシストが別の標的に切り替えました。新しい標的の側で鳴ります。オート射撃中は撃破後には鳴りません。

これらはすべて F4 → サウンドガイド で聞くことができ、左右矢印でそれぞれの方向から聞けます。 戦闘中は、Q で直前に聞こえた音の名前を読み上げます。

サウンドフィルター（数字キー）

戦闘中、数字キーで音のグループをミュートまたは解除して、集中できます。これらのキーはゲームでは使われていません。

キー グループ
1 敵：ドラム、うなり声、攻撃の準備、ボスの登場
2 ボール：転がるようなハム音、カチッという音、キャッチ、ミス、銃のラック
3 報酬：ジェム、金貨、資源、特殊アイテム
4 弾と危険
5 アリーナの端
6 自分の体力：ダメージ、回復、心音、状態
7 エイムアシストのクリック音
0 すべて元に戻す
  • 数字キーはそれぞれ自分のグループだけを切り替え、ほかのグループには影響しません。
  • Ctrl+数字 で、そのグループだけを残します。例：敵と報酬だけにするには、Ctrl+1、続けて3。
  • 選んだ設定は次回も保持されます。何かをミュートした状態で戦闘が始まると、MODが何をミュート中か読み上げます。
  • ミュートで変わるのは音だけです。H、J、P、Nのキーは引き続き応答し、キャッチアシストも引き続き弾をよけます。

アシスト

アシストが行うことは、すべて耳だけでも行えます。アシストは、使いたいときのためにあります。

  • エイムアシスト（F5でモードを変更）：最も近い敵（初期設定）、最も強い敵、正面の敵、固定角度のいずれかを 代わりに狙います。オフ（マウス）にもできます。矢印キーで微調整できます。ほかの敵に隠れていない部分を狙い、ヒーローが撃てない角度の敵は飛ばし、標準モードでは、ほかの敵がすぐ届きそうでない限りボスを優先します。
  • キャッチアシスト（Shift長押し）：主人公が、次に落ちてくるボールの下へ歩きます。ボールが来ていないときは、 最も近いジェムやアイテムへ歩きます。弾が当たりそうなときは、まずそれをよけます。W / Sでは引き続き前後に移動 でき、A / Dを押すと常にそちらが優先されます。F4では、オフ、「Shift長押し」（初期設定）、自動を選べます。ダメージを受けているときは、先に回復アイテムを取りに行きます。

MOD設定（F4）

上下矢印で移動、左右矢印かEnterで変更、Escで閉じます。設定は保存されます。

  • エイムアシストのモード
  • キャッチアシスト：オフ、Shift長押し、自動
  • ガイド音のオン / オフ、ガイド音の音量
  • 敵のレーダー、ボールの音、アリーナの端、弾と危険（オン / オフ）
  • アイテムの音：オフ、特殊アイテムのみ、すべて
  • 体力の音、エイムアシストのクリック音（オン / オフ）
  • フォーカス時にアップグレードの説明を読む
  • コントローラー
  • キー（Enterで開く）：キーの変更を参照
  • サウンドガイド（Enterで開く）
  • デバッグログ
  • 戦闘の記録（初期設定はオフ）：すべての戦闘を UserData\BallPitAccess\telemetry.tsv に書き出します（音の調整用）

キーの変更

F4 → キー に、MODのすべてのキーと、いま割り当てられているキーが並びます。上下矢印で選び、Enter を押してから 新しいキーを押します（Escでキャンセル）。Delete で初期設定のキーに戻し、最後の行ですべてを戻します。新しいキーが すでに別のMODの操作に使われていれば、2つが入れ替わり、もう一方がどこへ移ったかをMODが読み上げます。メニューや ゲームが使うキー（矢印、Enter、Tab、Esc、BackSpace、スペース、W A S D F E R X）は割り当てられません。F1のヘルプの 最後で、いまの設定のキーが読み上げられます。

コントローラー

  • ボタン名はXboxのものです。PlayStationやSwitchのコントローラーは、このゲームでSteam Inputをオンにすると使えます
  • 戦闘の外では十字キーか左スティックが矢印キーのように動き、AはEnter、Bは戻るです
  • XとYは最初と最後の項目へ移動します。建物を配置中は、Xが置ける場所を探し、Yが回転させます
  • RBとLBはTabとShift+Tab、RTとLTは画面のタブを切り替えます
  • Startはゲームのポーズです
  • 戦闘中はスティック、トリガー、ボタンはゲームが使います
  • 十字キーの上で敵、下で体力、左で状態、右で進行状況を読み上げます
  • 左スティックを押し込んだままにするとキャッチします（Shiftと同じ）
  • 右スティックに触れなければ照準アシストが狙います。動かすと自分で狙えます
  • Viewを押したままで、A ヘルプ、B MOD設定、X 画面を読む、Y 繰り返し、Start 照準モード切り替え
  • ViewとLB、RBで確認リストの古い行と新しい行を読み、Viewとスティック押し込みで詳細とイベントを切り替えます
  • 戦闘中のViewと十字キー：上 危険、下 装備、左 アイテム、右 最後の音。ViewとLT、RTでゲーム速度を下げる、上げる
  • 拠点でのViewと十字キー：上 収穫、下 資源、左 探索モード
  • メニューではViewとLT、RTがPage UpとPage Downです

最初のランのコツ

  • ボールをキャッチしましょう。 キャッチしたボールはすぐにまた発射できます。取り逃したボールは、戻ってくるまで 2〜3秒かかります。カチッという音が聞こえるまで転がるようなハム音を追いかけ、聞こえたらそこにとどまります。
  • 経験値ジェムを拾いましょう。 自動では集まりません。ガラスのチンという音を追いかけてください。こもった音は 後ろにあることを示します。
  • まずは生き残ること。 ランの序盤は、ダメージよりも生き残ることのほうが大切です。
  • レベルアップで提案されたら、ボールを融合・進化させましょう。選択肢には「融合」または「進化」と読み上げられます。
  • ボス戦ではNum -（テンキーの-、またはゲームのマイナスキー）で遅くしましょう。 高いゲームスピードでボスが登場すると、MODが知らせてくれます。
  • 倒れるのは普通のことです。持ち帰った金貨でニュー・ボルビロンを発展させ、建物がその後のランを強くしてくれます。

既知の制限

  • 拠点にある放置用の発射台は、まだマウスが必要です。
  • ランキングとTwitch投票は、基本的な読み上げにしか対応していません。クレジットはスキップできません。
  • MOD設定はF4にあり、ゲーム本来のオプション画面の中にはありません。
  • 英語とスペイン語以外の言語のMOD独自のテキストは、まだネイティブスピーカーによる確認を経ずに翻訳されています。 訂正を歓迎します。ゲーム由来の名前（建物、ボール、敵、アップグレード）は、常にゲーム自身の翻訳から取得されます。
  • 音量、音の間隔、キャッチの幅は、まだプレイヤーと一緒に調整していません。

問題の報告

ゲームフォルダー内の役に立つファイル：

  • UserData\BallPitAccess\speech.log：MODが話したすべての内容。
  • MelonLoader\Latest.log：MODのログ（エラー、画面、キャッチとミス）。
  • 戦闘中に Ctrl+Shift+D を押すと、UserData\BallPitAccess\threats.txt（敵、ボール、弾、アイテムとその位置） を書き出し、開いている画面のリストを Latest.log に書き込みます。音が間違った方向を示すときや、メニューが 間違った順番で読まれるときに役立ちます。
  • UserData\BallPitAccess\telemetry.tsv：F4 → 戦闘の記録 をオンにした場合。戦闘中のすべての音、敵、ボール、 弾が記録されます。音が聞き分けにくいときに最も役立ちます。

何をしたか、何が聞こえたか、何を期待していたかを書いてください。
